## Implementation Overview

Контракт сначала: типы, константы, сигнатуры всех модулей и связка тика пишутся одной рукой (TSK-001…003). Затем волнами:
- **Волна 1** — агенты параллельно реализуют модули симуляции. Каждый агент работает в своих файлах, тесты пишет рядом.
- **Связка** — интеграция, боты баланса.
- **Волна 2** — интерфейс: сначала оболочка, затем окна параллельно.
- **Волна 3** — проверка в браузере, ревью, баланс.

Каждая задача заканчивается зелёными `npx vitest run <свои тесты>` и `npx tsc -b --noEmit`.

- **Правила для агентов:** правят только файлы своей задачи. Если нужен новый общий тип или константа — добавить локально в свой файл и написать об этом в отчёте. Чужие модули в тестах могут быть ещё заглушками, поэтому тесты строят входные данные сами или используют `vi.mock`.
