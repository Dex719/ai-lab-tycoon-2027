# Рынок v2: подписки, типы клиентов, уровни моделей - требования

Источник: отзывы владельца в ночь на 12.10.2026 (скриншоты 1-10 и ответы на вопросы). Формулировки владельца сохранены в кавычках, ниже - принятые решения.

## 1. Каналы продаж и доли мощности

«Думаю стоит добавить подписки? И менять долю мощностей с API на подписки.»

- Два канала продаж у каждой модели: **API** (оплата за токены, как сейчас) и **Подписка** (оплата в месяц за пользователя, чат-продукт).
- В окне «Мощности» доля «Клиенты» делится на две: **«API»** и **«Подписки»**. Итого пять долей: Обучение, Контракты, Исследования, API, Подписки.
- Подписки появляются по истории: чат-продукты возникают с «чат-момента» (ноябрь 2022, ChatGTP). До этого канал подписок закрыт или почти пуст. API для разработчиков - с 2020 года (GTP-3), до этого рынок маленький, как сейчас.

## 2. Типы клиентов

«Разделить клиентов на обычных, enterprise и мб кодеры.»

- Три сегмента спроса: **обычные** (люди: подписка на чат; ценят известность, цену подписки, удобство, длинный контекст), **корпоративные** (компании: API и подписка для сотрудников; ценят Эло, надёжность, контекст, отсутствие скандалов с подгонкой), **разработчики** (API: ценят цену за токен, баллы по коду - HumanEvol, SWE-banch, контекст).
- У каждого сегмента своя кривая спроса по годам и свои веса факторов. Доли рынка считаются по сегментам, в интерфейсе видно, где игрок силён.

## 3. Уровни моделей и цены

«Мб нужно добавить типо уровни моделей и их цену. Например haiku супер дешёвая и слабая.»

- При создании модели выбирается **уровень**: «Лёгкая» (дёшево и быстро, слабая), «Средняя», «Флагман». Уровень задаёт диапазон размера и данных относительно переднего края года, цену за токены и подписку по умолчанию, стоимость обслуживания (лёгкая модель обслуживает больше пользователей на одну видеокарту).
- Сегменты по-разному относятся к уровням: разработчики любят дешёвые, корпоративные - флагманы, обычные - средние и флагманы в чате.
- Цены игрок может менять: цена за 1 млн токенов (API) и цена подписки в месяц.

## 4. Несколько моделей сразу

«И мб возможность выпускать сразу несколько моделей.»

- Одновременно может идти до двух обучений; доля «Обучение» делится между ними.
- В продаже одновременно может быть несколько моделей разных уровней (это уже возможно, нужно сделать очевидным в интерфейсе).

## 5. Проверка сильных моделей

«Модели уровня высокого в кодинге и в целом типа Mythos через проверку должны проходить, и можно будет модель ограничить от подписки.»

- Модель, которая заметно сильнее переднего края (по Эло или по коду), перед выходом в подписку проходит **внешнюю проверку**: занимает время и деньги. Пока проверка не пройдена, модель можно продавать только по API корпоративным клиентам и разработчикам, либо не продавать вовсе.
- У каждой модели есть переключатели каналов: «API», «Подписка». Игрок может сам ограничить сильную модель от подписки.

## 6. Что не меняется

- Детерминированная симуляция, сохранения старых партий загружаются (поля по умолчанию).
- Соперники: у их моделей уже есть признак `chat`; они продают по тем же каналам.
- Инвесторы оценивают компанию по общей выручке (API + подписки + контракты).

## 7. Связанные правки интерфейса (та же ночь)

- Окно «Мощности»: ползунки не двигают друг друга, рядом поле с процентом, строка «Занято: N %», ошибка показывается после «Распределить», долю 0 % для API или подписок можно подтвердить.
- Везде, где показаны H100e, мелкими цифрами показывать число видеокарт.
- Уведомления в игре: всплывающие сообщения «Пришло письмо», «Обучение завершено», «Тендер выигран» и подобные.
