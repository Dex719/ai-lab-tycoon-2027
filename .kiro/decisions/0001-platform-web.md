# 0001. Платформа: веб (TypeScript + React), позже Tauri

## Status
accepted (владелец, 2026-10-11)

## Context
Игра для себя, интерфейс в духе Processor Tycoon: окна, таблицы, графики, почта. Владелец не разработчик, поэтому агент должен сам запускать игру, кликать и проверять изменения. Node.js 24 и npm 11 на машине уже есть. Unity отвергнут: редактор весит ~10 ГБ, и проверить игру без владельца нельзя. Godot лёгкий, но проверять его агенту тоже сложнее, чем браузерную игру.

## Decision
- Игра — веб-приложение на TypeScript + React, сборка Vite.
- Симуляция (дни, деньги, рынок, соперники) — чистый TypeScript без React, покрыт автотестами.
- Время — реальное с паузой и скоростями ×1/×2/×4 (решение владельца).
- Сохранения — в браузере, с выгрузкой и загрузкой файла.
- Позже — упаковка в `.exe` через Tauri.
- Git — локальный репозиторий, автор коммитов — владелец, без AI-атрибуции; приватный GitHub — позже, когда появится играбельный срез.

## Consequences
- Плюс: агент сам запускает игру во встроенном браузере, делает скриншоты и тестирует; ничего не нужно ставить.
- Плюс: логику проверяют быстрые тесты без браузера.
- Минус: для `.exe` через Tauri позже понадобится Rust (отдельная установка, спросить заранее).
