# AI Lab Tycoon 2027

Браузерная экономическая стратегия в духе Processor Tycoon. Вы основываете лабораторию искусственного интеллекта в 2017 году и за восемь лет пытаетесь обогнать OpenBrain, Antropik, Gogle DeepMynd и других. Сюжет опирается на сценарий «AI 2027» и реальную историю моделей 2017-2024 годов.

Цель партии - к 31.12.2024 вывести модель на 1-е место «Арены» среди моделей, которые продаются по API.

## Что есть в игре

- **Исследования.** Карта технологий: механизм внимания, законы масштабирования, RLHF, длинный контекст, смесь экспертов, дистилляция и другие. Изучать технологию раньше её исторической даты можно, но дороже.
- **Мощности.** Аренда видеокарт от P100 до H200 и распределение мощности между обучением, контрактами, исследованиями, API и подписками.
- **Обучение моделей.** Размер, данные, контекст, уровень («Лёгкая», «Средняя», «Флагман»), подгонка под бенчмарки с риском разоблачения. Одновременно можно вести два проекта.
- **Рынок.** Продажи по API и по подписке. Три типа клиентов: обычные пользователи, компании и разработчики. Цены, доля рынка, мощность на обслуживание.
- **Бенчмарки и «Арена».** Тесты появляются и «насыщаются» по истории, рейтинг Эло.
- **Контракты.** Тендеры на дообучение и RLHF для вымышленных клиентов.
- **Инвесторы.** Раунды финансирования и доля основателя. Если доля падает ниже 50 %, вмешивается совет директоров.
- **Соперники с характерами.** Семь лабораторий отвечают на ваши успехи: снижают цены, ускоряют флагманы, выпускают дешёвые модели, проверяют ваши баллы. Каждый ход сначала приходит слухом в почте.
- **Сложность.** «Лёгкая», «Обычная», «Сложная».
- **Каталог.** 76 реальных моделей семи лабораторий с датами, ценами, баллами и контекстом. Названия изменены на 1-2 буквы.
- **Обучение игре** для новичков, сохранения в ячейках, вёрстка для телефона и планшета.

## Запуск

Нужен Node.js 22 или новее.

```bash
npm install
npm run dev
```

Откройте http://localhost:5317. Пробел - пауза, кнопки справа от даты - скорость.

Сборка и тесты:

```bash
npm run build
npm test
```

## Оригинальные названия

В игре пародийные названия: OpenBrain, ChatGTP, Gemeni, SQuAT. Чтобы видеть настоящие (OpenAI, ChatGPT, Gemini, SQuAD), включите в главном меню «Настройки» → «Оригинальные названия». Перезагрузка не нужна.

Переключатель меняет только то, что показано на экране: симуляция и сохранения остаются с игровыми названиями. Словарь замен - `src/data/realNames.ts`, подстановка в интерфейсе - `src/ui/realNamesDom.ts`.

## Устройство проекта

- `src/sim` - симуляция: детерминированная, без обращений к интерфейсу, покрыта тестами (`vitest`).
- `src/data` - данные: лаборатории, каталог моделей соперников, бенчмарки, видеокарты, события.
- `src/ui` - интерфейс на React.
- `research/` - исходные данные каталога (модели, контекст, цены) с источниками.
- `scripts/build-rival-catalog.mjs` - сборка каталога из `research/` в `src/data/rivalModels.ts`.
- `.kiro/specs/` - спецификации срезов с формулами баланса.
- `PROGRESS.md` - журнал работы и текущее состояние.

В консоли браузера в режиме разработки есть `__game`: например, `__game.autoplay(365)` - бот сыграет год за вас.
